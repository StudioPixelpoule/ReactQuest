# ReactQuest 🚀

Une aventure interactive pour maîtriser React et TypeScript en construisant des projets réels.

## 🌟 Fonctionnalités

- **Apprentissage Interactif** : Apprenez React à travers des quêtes pratiques et guidées
- **Progression Structurée** : Des quartiers thématiques pour une évolution logique
- **Feedback en Temps Réel** : Validation instantanée du code et conseils personnalisés
- **Interface Immersive** : Design moderne avec effets visuels et sonores
- **Sauvegarde Automatique** : Progression conservée entre les sessions

## 🏗️ Architecture du Projet

```
src/
├── assets/         # Ressources statiques (images, audio, styles)
├── components/     # Composants React réutilisables
├── lib/           # Logique métier et utilitaires
├── pages/         # Composants de pages
└── types/         # Types TypeScript
```

## 🛠️ Technologies Utilisées

- **Frontend** :
  - React 18
  - TypeScript
  - Vite
  - Tailwind CSS
  - Framer Motion
  - shadcn/ui

- **État** :
  - Zustand
  - React Query

- **Validation** :
  - Zod
  - React Hook Form

- **Tests** :
  - Vitest
  - Testing Library

## 🚀 Démarrage

1. **Installation des dépendances** :
```bash
npm install
```

2. **Lancement en développement** :
```bash
npm run dev
```

3. **Construction pour production** :
```bash
npm run build
```

4. **Lancement des tests** :
```bash
npm run test
```


Le thème peut être personnalisé via `tailwind.config.js` et les variables CSS dans `src/index.css`.

## 📝 Conventions de Code

- **TypeScript** : Types stricts obligatoires
- **Components** : Un composant par fichier
- **Tests** : Requis pour les composants principaux
- **State** : Zustand pour l'état global
- **Styles** : Tailwind CSS avec classes utilitaires
